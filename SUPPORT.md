# Support

1. Run `CodexProfile.ps1 -Action doctor`.
2. If you see `stale-swap-lock`, run `-Action repair` after closing every Codex window.
3. For GitHub issues, attach `-Action diagnostics` output (or a redacted launch-trace). Never upload `auth.json`.

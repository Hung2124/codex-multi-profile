# Support

1. Run `CodexAccounts.ps1 status` (in `%LOCALAPPDATA%\CodexMultiProfile`).
2. If you see `stale-swap-lock`, run `-Action repair` after closing every Codex window.
3. For GitHub issues, attach the `status` output and the relevant lines of `codex-accounts.log` (emails are masked). Never upload `auth.json` or the `accounts` folder.
